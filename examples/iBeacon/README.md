# iBeacon 送信サンプル

Arduino Nano 33 BLE Sense Rev2で、iBeacon形式のBLEアドバタイジングを送信するスケッチです。接続可能なBLEサービスは公開せず、UUIDや識別番号などを含む広告データをブロードキャストします。

## 設定値

`iBeacon.ino` の次の定数でビーコン情報を設定します。

- `BEACON_UUID`: ビーコンを識別する16バイトのUUID
- `BEACON_MAJOR`: ビーコン群の分類などに使う16ビット値
- `BEACON_MINOR`: 個々のビーコンの識別などに使う16ビット値
- `MEASURED_POWER`: 1m地点で測定したRSSIの目安をdBmで指定する符号付き8ビット値

`MEASURED_POWER` は距離推定の基準となる値です。現在の設定値 `-59` はサンプル値なので、実際に使う環境とボードで1m地点のRSSIを測定して調整してください。周囲の電波状況や設置条件によってRSSIは変動します。

## 実行方法

1. Arduino IDEにArduinoBLEライブラリをインストールします。
2. `iBeacon.ino` をArduino IDEで開きます。
3. ボードに `Arduino Nano 33 BLE Sense Rev2` を選択し、ポートを設定します。
4. スケッチをコンパイルしてボードへ書き込みます。
5. シリアルモニターを `115200` baudで開きます。
6. BLEスキャナーでビーコンの広告を確認します。

スケッチは起動時に最大10秒間シリアル接続を待ちます。BLEの初期化に失敗すると、エラーメッセージを表示して停止します。

## 広告の内容と動作

広告データにはAppleのCompany Identifier (`0x004C`)、iBeacon識別子 (`0x02 0x15`)、UUID、Major、Minor、測定電力が含まれます。MajorとMinorは上位バイトから順に格納します。アドバタイジング間隔は100msで、ビーコンは接続不可に設定されています。

起動時に送信開始メッセージとBLE MACアドレスを表示し、その後も5秒ごとに送信中のメッセージとMACアドレスを表示します。シリアル出力はデバッグ用で、ビーコン送信自体はBLE広告によって行われます。

## 注意事項

- このスケッチはArduinoBLEに対応するBLE搭載ボード向けです。記載したNano 33 BLE Sense Rev2以外では、ボードやArduinoコアの対応状況を確認してください。
- UUID、Major、Minorが同じビーコンを複数設置すると、受信側で個体を区別できない場合があります。
- 広告に含めたUUIDなどの情報は周囲のBLEスキャナーから受信できます。公開してよい値を設定してください。
