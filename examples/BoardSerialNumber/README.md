# Board Serial Number

このスケッチは、Nordic Semiconductor nRF52シリーズのマイコンに保存されているデバイス識別情報を読み取り、シリアルモニターに表示するサンプルです。

## 表示する情報

- `DEVICEID[0]`、`DEVICEID[1]`: マイコンのデバイスIDを構成する2つの32ビット値
- `DEVICEADDR[0]`、`DEVICEADDR[1]`: マイコンに関連付けられたデバイスアドレス情報を構成する2つの32ビット値

値は16進数で表示されます。スケッチはこれらを5秒ごとに繰り返し出力します。出力例は次のとおりです（値はボードごとに異なります）。

```text
Device ID 0: 12345678
Device ID 1: 9ABCDEF0
Device Address 0: 12345678
Device Address 1: 000000AB
```

実際の出力値を、上記の例の値と混同しないでください。

## 実行方法

1. `BoardSerialNumber.ino` をArduino IDEで開きます。
2. `NRF_FICR` が利用できるnRF52対応ボードと、そのボード用のArduinoコアを選択します。
3. スケッチをコンパイルしてボードへ書き込みます。
4. シリアルモニターを開き、通信速度を `9600` baudに設定します。
5. デバイスIDとデバイスアドレスが5秒間隔で表示されることを確認します。

`setup()` 内でシリアル接続を待つため、シリアルモニターを開くと出力が始まります。

## 注意事項

- このスケッチは `NRF_FICR` というNordic nRFのレジスター定義を使用します。すべてのArduinoボードで動作するわけではありません。対象ボードのArduinoコアがこの定義を提供している必要があります。
- ソースには `ArduinoBLE.h` が含まれていますが、このスケッチではBLEの初期化や通信は行いません。
- デバイスIDやアドレスは、ボードを識別できる情報として扱ってください。ログや画面の画像を共有する際は、実際の値を公開してよいか確認してください。
